# Glossary

A minimal vocabulary for navigating the public technical repositories of **El Canal — Applied Cognitive Symbology (ACS)**.

| Term | Meaning |
|---|---|
| **ACS** | **Applied Cognitive Symbology**. The wider research framework in which El Canal develops its public methods, protocols and artefacts. |
| **CAP** | **Canal Activation Protocol**. A minimal operational protocol for sustaining a conscious, portable and non-dependent human–LLM working relationship. CAP is not an autonomous agent or a prompt product. |
| **PTC / CTP** | **Protocolo de Transparencia Canalista / Canal Transparency Protocol**. The normative transparency protocol for declaring and making AI participation technically inspectable. |
| **R-01** | Canonical Text Specification. Defines the canonical textual object used by the PTC/CTP stack. |
| **PTC-F** | Functional Specification of PTC/CTP. Defines normative fields and functional behavior. |
| **ARCH** | Normative Architecture and Governance Specification for PTC/CTP. |
| **FRS-01** | `file-reference-sha256-v1` profile. Protects an exact file reference using SHA-256. |
| **PKG-02** | Validator Package Format 2.0. Defines transport, preservation and reconstruction of a verifiable package. |
| **DCL-03** | `disclosure-notice-v1` profile. Defines a verifiable public disclosure notice for AI-generated or AI-modified content. |
| **Validator** | Reference implementation of PTC/CTP. It creates and verifies PTC declarations locally in the browser. |
| **El Canal Corpus** | Machine-readable public registry of DOI-bearing El Canal artefacts, versions, metadata and explicit relations. |
| **PRI-1.0** | A related line of work on human–AI intermediation referenced by *La sal del eclipse*. It is not part of the mandatory CAP core. |
| **LEA** | **Lógica Ética Aplicada / Applied Ethical Logic**. A public line within the broader ACS corpus. |
| **MOA** | **Música Operativa Aplicada / Applied Operative Music**. A public experimental line within the broader corpus. |
| **Zenodo** | Archival and citation authority for closed public releases. |
| **elcanal.es** | Human-facing conceptual navigation layer for the wider project. |

## Relationship between CAP and PTC/CTP

They are complementary, not interchangeable.

- **CAP** asks: *How do we work with an AI over time without losing human control, context discipline or portability?*
- **PTC/CTP** asks: *How do we transparently declare and technically verify AI participation in an artefact?*

Validator implements PTC/CTP. The corpus registers the public artefacts and their relations.
